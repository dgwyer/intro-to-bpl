# Intro to BPL

I made these 16 sample dialogs in SolveIt while learning [BasedPL](https://answerdotai.github.io/basedpl/).

## Run in SolveIt

1. In SolveIt, open the folder where you want to keep the dialogs. From the file list, press **Shift+T** to open that folder's terminal.
2. Paste this command and press **Enter**. It creates an `intro-to-bpl` folder.

   ```sh
   git clone https://github.com/dgwyer/intro-to-bpl.git
   ```

3. Return to the SolveIt file list and refresh the page. Open `intro-to-bpl`, then `dialogs`. Click any numbered chapter to open its dialog.
4. Run the setup cells at the top in order. They install BasedPL and enable the `%%bpl` magic. Then use the **Run** button on each `%%bpl` cell to try the examples in order.

Chapter 9 creates a scratch folder named `bpl-files` and deletes it at the end.
